# Brand guide (verified from pikment.az CSS and logo SVG)
- Violet #4524F5 / #6d4aff (site accent), second violet #7845F5, lavender #AD60EF, blue #3460F5, sky #21A0FF. Orange #FF951F is an accent only (it is the logo's last tone).
- Backgrounds: light lavender #F4F2FC / white dominate. Ink #171428. Dark surface #15132B only inside real site screenshots.
- Fonts: Manrope (display, 200-800), Inter (body). Bundled in `remotion-composer/src/fonts` (latin + latin-ext: all of Ə ə Ğ ğ Ş ş Ç ç Ö ö Ü ü İ ı).
- Logo: only `pikment-studio/brand/logo/*.svg` / `src/pikment/Logo.tsx`. Never redraw, recolour or distort. Its gradient (blue -> violet -> orange) may slide across the mark.
- Format: Reels 9:16, 1080x1920, 30 fps, H.264. Keep text inside y 250..1500 (Instagram UI safe area).
- Motion: kinetic typography, mask reveal, match cut, expo-out easing, subtle parallax, real device mockups. No neon/glow/template effects.
