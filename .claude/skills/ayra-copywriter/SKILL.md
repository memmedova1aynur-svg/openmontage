# AYRA Ad Creative

## Prinsip
Reklam ekspertin real sözü və real təklifi üzərində qurulur. Uydurma rəqəm, qiymət, nəticə, rəy yoxdur — bilinməyən fakt `[kvadrat mötərizə]` boşluğu kimi qalır.

## İş axını
1. **Brif** — təklif (təlim/xidmət adı, tarix, format, qiymət — yalnız müştəri verirsə), auditoriya (`strategiya.md`), istənən hərəkət (DM, qeydiyyat linki, zəng).
2. **Bucaqlar** — 3 fərqli bucaq: problem (auditoriyanın real vəziyyəti), transformasiya (təlimdən sonra nə bacaracaq), ekspert (niyə bu adam). Bucaq başına 3 hook (ilk 2 s, ekranda ≤7 söz).
3. **Ssenari** — 15/30/45 s versiyaları: hook → kontekst → təklif → sübut (yalnız real) → CTA. Danışıq dili, qısa sətirlər, tam mətn.
4. **Vizual konsept** — `ayra-design-director` ilə: kadr planı, ekran yazıları, motion cihazları (`ayra-motion-designer`), cover (`ayra-professional-cover-designer`).
5. **Test planı** — hansı hook/bucaq müqayisə olunur, hansı metrika (izləmə müddəti, DM sayı). Nəticə proqnozu yazma.

## Çıxış formatı
```
Bucaq / Hook (ekran + səs) / Ssenari (zamanla) / Ekran yazıları / CTA / Lazımi kadrlar / Boşluqlar [...]
```

## Qaydalar
Agitasiya, qorxu satışı, "son şans" yalanı yoxdur; ekspertin şəxsi çətinlikləri göstərilmir. Bir reklam — bir təklif — bir CTA.

## Əməkdaşlıq
Köməkçi: `ad-creative`, `copywriting`, `marketing-psychology`, `offers`, `launch`, `pricing`, `meta-ads`, `ig-human` (mətnin AI tonunu təmizləmək). Ötürür: `ayra-motion-designer`, `ayra-professional-cover-designer`; yoxlama: `ayra-visual-design-critic`.

## Təbii Azərbaycan dili — AI izlərinin qadağası (16.11.2026, studiya qaydası)
Qadağan strukturlar: «Bu, sadəcə X deyil, Y-dir» · «Bəlkə də problem düşündüyünüz yerdə deyil» · «Unutmayın ki…» · «Hər şey bir addımla başlayır» · «…dünyasına birlikdə səyahət edək» · «Hər bir uşaq özünəməxsusdur» · boş motivasiya, süni emosiya, tərcümə dadı verən cümlələr, eyni cümlə qəlibinin təkrarı, mənasız sual-cavab, dramatik/manipulyativ hook.
Hər mövzunu «5 üsul / 7 səbəb» formatına salma. Mexanizmi mövzudan seç: real situasiya, tanınan müşahidə, ziddiyyət (məs. «Hamı təbrik edir, sən isə ağlamaq istəyirsən»), müqayisə, eyni suala 3 fərqli cavab, ekspert müşahidəsi, paylaşılan faydalı material (məs. qonaq üçün «Menyu»).
Proses: strategiya (kim, hansı problem, məqsəd: çatma/etibar/fayda/satış) → 3–5 başlıq variantı → təbiilik, diqqət gücü, uyğunluq, brend tonu üzrə müqayisə → seçim + 1 cümlə səbəb → ən azı 2 vizual konsept → dizayn → render edilmiş şəkilə baxaraq kreativ direktor yoxlaması.
Tibbi/laktasiya iddiaları yalnız təsdiqli mənbə və ya Suranın öz sözü; yoxlanılmamışı «Sura təsdiqləməlidir» kimi işarələ.

## Marketinq kopirayter qaydaları (Creative Intelligence)
- Başlıq konkret həyat səhnəsidir: «Uşağın bacardığı işi niyə onun yerinə edirik?», «Bağçada bütün gün sakit olan uşaq evdə niyə ağlayır?» — ümumi şüar yox («Onun yerinə az et», «Bəs əgər…» zəifdir).
- Qadağan strukturlar: «X deyil, Y-dir» təkrarı; «Bəlkə də problem düşündüyünüz şey deyil»; mövzuya bağlı olmayan motivasiya; süni dramatizm; çox emoji; bir postda birdən çox CTA.
- Eyni başlıq strukturunu seriyada təkrarlama (sual → sual → sual yox; sual / rəqəm / səhnə / sitat növbələşir).
- 3–5 başlıq variantı yaz, birini səbəbi ilə seç (`brief.md`).
- Tibbi/psixoloji/pedaqoji iddia uydurma; yaş həddi, təhlükəsizlik (kiçik əşyalar, ip, boğulma riski) olan yerdə «valideyn nəzarəti» qeydi və «mütəxəssis təsdiqi lazımdır» işarəsi.
- Yerli sözlər: «şərf» yerinə kontekstə görə «kəlağayı»; tərcümə hissi verən söz sırası yox.
