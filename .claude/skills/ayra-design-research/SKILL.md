# AYRA Design Research

## Mənbələr
- `templates/ayra/taste/TASTE_LIBRARY.md` — prinsiplər, istiqamət kataloqu, mənbə əlçatanlıq jurnalı (saytların hansının açıldığı orada qeydlidir).
- `templates/ayra/taste/taste_examples.json` — analiz olunmuş nümunələr (yalnız link və təhlil; şəkillər repoya yazılmır).
- `templates/ayra/taste/PRO_STANDARD.md` — tənqidçinin portfolio standartı.
- Gizli: `instagram-clients/_agency/approved_library.md` (Approved + Rejected), müştərinin `visual-dna.md`.

## İş axını
1. Tapşırığın kateqoriyası və istiqaməti → kitabxanadan uyğun qaydalar və nümunə id-ləri.
2. Lazımdırsa yeni araşdırma: curl/WebFetch ilə səhifə → şəkli endir (scratchpad) → Read ilə BAX → təhlil → `taste_examples.json`-a əlavə et. Bloklanan sayt = jurnala "bloklanıb".
3. Moodboard (yalnız daxili, "önizləmə" adı ilə): 6–9 nümunə + çıxarılan 3–5 qayda.
4. İstifadəçi təsdiq/rədd edəndə Approved/Rejected-ə tarix + səbəb.

## Qayda
Kopyalama yoxdur — prinsip götürülür. Production Mode-da araşdırma yalnız kitabxanadan (yeni axtarış yox).
