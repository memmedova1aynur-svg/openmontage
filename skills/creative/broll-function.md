# B-roll Function — hər kadrın məcburi funksiyası

`broll-planning.md` stock/generated seçimi və sorğu texnikasını verir. Bu skill **niyə** B-roll qoyulduğunu məcbur edir.
**Qayda:** funksiyası və izah etdiyi fikri yazıla bilməyən kadr QOYULMUR. "Boşluğu doldurmaq" funksiya deyil.

## 7 funksiya (ən azı biri)
| Kod | Funksiya | Yoxlama sualı |
|---|---|---|
| `explain` | fikri izah edir | kadr olmadan fikir daha çətin anlaşılırmı? |
| `emotion` | emosiyanı gücləndirir | kadrın hissi danışığın tonuna uyğundur? |
| `metaphor` | vizual metafora | metafora mövzuya və auditoriyaya aydındırmı? (klişe deyil) |
| `concretize` | məlumatı konkretləşdirir | danışıqdakı rəqəm/obyekt/yer göstərilir? |
| `refresh` | diqqəti yeniləyir | uzun eyni plan var və yeni kadr mənaya xidmət edir? |
| `story` | hekayəni irəli aparır | kadr hadisəni/zamanı/məkanı davam etdirir? |
| `compare` | müqayisə göstərir | iki tərəf eyni çərçivədə ədalətli görünür? |

## Plan qeydi (hər B-roll üçün 1 sətir)
```
at 12.4s | dur 2.0 | explain | "gün işığında yuxu hormonu azalır" → pəncərədən səhər işığı (real) | mənbə: müştəri/stock-CC0
```
Sahələr: vaxt (danışıqdakı söz/cümlə), funksiya, **izah etdiyi fikir** (transkriptdən), kadr təsviri, mənbə + lisenziya.

## Seçim sırası (üstünlük)
1. Müştərinin real foto/videosu.  2. Mövzuya birbaşa aid real stock (yalnız qeydsiz kommersiya lisenziyası: Mixkit,
Wikimedia CC0/PD, Pixabay açarla — lisenziya hələ təsdiqlənməyibsə istifadə etmə).  3. Yüksək keyfiyyətli qrafik izah
(danışıqdakı rəqəm/addım ilə).  4. Yaradıcı kompozisiya/metafora.

## YOX
- Mövzuya aid olmayan stock ("işgüzar əl sıxma", "gülən qadın laptopla").
- Mənasız AI animasiya, çox sadə illüstrasiya, ucuz görünən motion graphics.
- Danışıqda olmayan rəqəm/fakt/vəd qrafikdə; real olmayan məkanı həqiqi kimi göstərmək.
- Müştəri profilində animasiya qadağandırsa — animasiyalı B-roll yoxdur, yalnız real kadr/statik.
- Üzü və CTA anını örtmək; hər 3 saniyədən mexaniki B-roll.

## Ölçü
30–60 s videoda 0–4 B-roll normaldır; 0 də düzgün ola bilər. Funksiya yoxdursa qoyma.
Təhvildə B-roll-un mənbə/lisenziya siyahısını qısa ver.
