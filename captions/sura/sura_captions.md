# Sura Malik: Reels caption-ları

## Video 01

```
Uşağı qucağa almaq onu ərköyün etmir. Bunu "qucağa öyrəşəcək" deyən hər kəsə göndərin.

Uşağın ağlaması ünsiyyət vasitəsidir. Ağlayırsa, nəyisə dilə gətirir: sancı ola bilər, anaya emosional ehtiyac ola bilər, gərginlik ola bilər.

Narahat pozisiya, yatmaq istəməmək, qucaq istəmək, ac olmadan əmmək istəmək. Bunların hamısı normaldır.

İlk üç ay hamiləliyin 4-cü trimestri kimidir. Bu dövrdə körpə ilə sıx kontakt onun psixoloji inkişafı üçün vacibdir.

Qucaq uşağın ehtiyacıdır.

#körpəbaxımı #yenianalar #anaüçün
```

## Video 02

```
"Qoy ağlasın, özü sakitləşər" yanaşması uşağa nə öyrədir? Videoya baxın və bağça müəllimi tanıyırsınızsa, ona göndərin.

Ağlayan uşağı sakitləşdirmək lazımdır. Əvvəlcə səbəbi tapırıq: kollektivə qarışmaq istəmir, böhran dönəmindədir, yoxsa bir əşya istəyir?

Sonra emosiyasını adlandırırıq: "Bilirəm, üzgünsən, o oyuncaqla oynamaq istəyirdin."

Bu gün emosiyası adlandırılmayan uşaq yeniyetməlikdə "tərbiyəsiz", "ərköyün" etiketi alır. Halbuki bunun bazasını kiçik yaşlarda biz qoyuruq.

#uşaqpsixologiyası #uşaqtərbiyəsi #anaüçün
```

## Video 03

```
2 yaşında hələ söz yoxdursa, "atası da gec danışıb" deyib gözləməyin. Postu yadda saxlayın.

Bu yaşda söz yoxluğu həyəcan təbilidir. Səbəb tənbəllik ola bilər: uşaq işarə edir, ana anlayır, danışmağa ehtiyac qalmır. Amma artikulyasiya aparatında problem, nitq və ya psixi inkişaf ləngiməsi də ola bilər.

SOS siqnalları:
işarələrlə danışır
avtonom nitqi yoxdur
2 sözlü cümlə qura bilmir
fikrini izah edə bilmir

Belə olanda loqopeddən və psixoloqdan dəstək alın.

#nitqinkişafı #uşaqinkişafı #anaüçün
```

## Video 04

```
Qatı qidaya nə vaxt və necə keçməli? Postu yadda saxlayın, başlayanda addım-addım lazım olacaq.

Optimal vaxt 4-6 ay aralığıdır. Çəki problemi və pediatr göstərişi varsa, 4 ayda başlamaq olar.

İlk dönəm doyumluq yox, dadımlıq dönəmidir:
tərəvəzlə başlayın, buxarda və ya suda bişirib əzin
3 gün qaydası: 1, 2, 3 qaşıq
ishal, qəbizlik, səpgi və narahatlığı izləyin
bir neçə tərəvəzdən sonra meyvəyə keçin

Meyvə şirindir və ana südünün dadına bənzəyir. Ondan başlasanız, uşaq tərəvəzdən imtina edə bilər.

#qatıqida #körpəqidası #anaüçün
```

## Video 05

```
Qorxan ana hər məsləhətə inanmağa başlayır. Bunu hiss edirsinizsə, səhifəni izləyin, burada doğru məlumat var.

"Südün yağsızdır", "uşağa su ver", "südün çatmır", "mütləq bunu ye". Hər kəs bir şey deyir.

Bu qədər səs arasında ana məlumatla yox, qorxu ilə qərar verir.

Laktasiya dəstəyi təkcə süd haqqında danışmaq deyil. Anaya doğru məlumatla özünə güvənməyi öyrətməkdir.

#anasüdü #laktasiya #yenianalar
```

## Video 07

```
Uşağın əli soyuqdursa, bu, üşüdüyü demək deyil. Qışdan əvvəl postu yadda saxlayın.

Üşüyüb-üşümədiyini kürək, sinə və bud nahiyəsindən yoxlayın. Bu nahiyələrdə qəhvəyi yağ toxuması var və bədənin istiliyini o təmin edir.

Otaq 20-22 °C olsa, bodi və slip bodi kifayətdir.

Çox qalın geyindirmək və bükmək uşağı isti salır. Belə olanda qidalanmadan, hətta məmədən imtina edə bilər.

#körpəbaxımı #yenidoğulmuş #anaüçün
```

## Video 08

```
Körpələrlə və analarla işləməyi sevirsənsə, bunu peşəyə çevirə bilərsən. Təlim haqqında məlumat üçün DM yaz.

Laktasiya məsləhətçiliyində yalnız məlumat bilmək kifayət etmir. Öyrənməli olduğun bacarıqlar:

ananı dinləmək
problemin səbəbini düzgün anlamaq
vəziyyəti qiymətləndirmək
lazım olanda uyğun mütəxəssisə yönləndirmək

Bunun üçün vacib addım sistemli təlim keçməkdir. Bəlkə də bir ananın "nə edəcəyimi bilmirdim" dediyi anda yanında olan mütəxəssis sən olacaqsan.

#laktasiyaməsləhətçisi #laktasiya #anasüdü
```

## Video 09

```
Yatan körpəni yemək üçün oyatmaq lazımdırmı? Cavab körpənin vəziyyətindən asılıdır. Postu yadda saxlayın.

Oyatmaq lazımdır, əgər:
3 aydan kiçikdir
çəki almasında problem var
sarılığı yuxarıdır

Sarılıq varsa, körpə daha çox yatmaq istəyir. Sarılığı aşağı salmaq üçün onu oyadıb qidalandırırıq.

Hər şey qaydasındadırsa, özü oyanana qədər gözləyə bilərsiniz. Yuxu 3-4 saatdan uzun çəkirsə, oyadıb yedizdirməyin faydası var.

Digər hallarda seçimi körpəyə buraxın ki, bədənin öz qurduğu yuxu rejimi pozulmasın.

#körpəyuxusu #anasüdü #yenianalar
```
